# Lunar port workmanship

**Status:** shipped, 2026-10-03, [PR #342](https://github.com/blisspixel/fragr/pull/342).
All eight [implementation CI checks](https://github.com/blisspixel/fragr/actions/runs/37165892071)
pass. Local full-client checks and an inspected 28-state route also pass.
**Spend:** $0. Existing pixel materials and authored geometry only.

## Goal

Make Port of Entry read as an inhabited working pressure port: an engineered
arrival threshold, strapped cargo, maintained overhead services, orderly customs
work surfaces and a readable transfer lane. Keep the original stylized pixel
house style and restrained circa 2070 industrial equipment. Earth, the family
window, confiscation cage and customs galleries remain the main landmarks.

## Boundaries and architecture

M06Port owns a local workmanship helper. Substantial fittings sit inside their
existing authoritative host solids; shallow paint and trim describe those solids.
Roof details remain at roof height. No collision, enemy logic, mission facts,
pressure mechanics, route geometry, protocol, shared renderer or paid assets
change. No new furniture suggests usable cover that the server does not own.

Only the actual map 1006 footprint selects its coordinate-specific fittings;
fixtures and different maps cannot accidentally receive port scenery. Existing
nearest filtered lunar textures, charcoal, bone and restrained Union red establish
continuity. Lights use the existing practical group and world visual layer.
The black/red Union identity belongs primarily to issued outfits. This increment
keeps broad port finishes in weathered steel and pale pressure-shell colors;
red is limited to small cargo seals and issued bulkhead trim.

## Verification and acceptance

Check host containment, maximum shallow protrusion, roof headroom, nearest
materials, finite node/light budgets, exact venue selection and map replacement.
Run the existing M06 presentation and mission harnesses. Run the unchanged
ordinary-input 25-state route with the existing release server and inspect actual
arrival, cargo, family window, customs and transit captures. Preserve all guard,
Rail, Turret cancellation, optional marker and shared departure requirements.

Headless checks establish structure, not visual quality. A rendered route proves
presentation along its actual states, not subjective fun, all difficulty levels
or general hardware performance. Full client and CI remain integration gates.

## Local result

[Evidence](../evidence/m06-world-workmanship-20261003.md) records 150 shallow
surface meshes, eight bounded practicals, four clean focused harnesses and the
full original 25-state gameplay route plus three camera-only inspection states.
All 21 named guards are defeated, real Rail and Turret lessons pass, the optional
route is marked and shared departure completes with zero deaths. Captures show
enclosing dock/freight/customs roofs and visible cargo locking straps. The attempted
ground-floor desk inspection is partly occluded by a real queue island and does
not establish a close visual acceptance of each desk detail.

Large sparse freight/customs deck areas still need an architecture and activity
review. This pass neither fills them with false cover nor closes whole-map art
acceptance. Desktop publication remains a separate gate.
